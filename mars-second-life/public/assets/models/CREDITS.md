# Character models

All four characters come from the three.js example models (https://github.com/mrdoob/three.js/tree/r181/examples/models/gltf), shipped with the MIT-licensed three.js repository.

| File | Origin | Used as |
| --- | --- | --- |
| `Xbot.glb` | Mixamo X Bot, three.js examples | Colony androids; its idle / walk / run / nod / head-shake animations drive every other body |
| `Michelle.glb` | Mixamo "Michelle", three.js examples | Colonist; its Samba dance is used in Nova Studio |
| `Gentleman.glb` | `readyplayer.me.glb`, Ready Player Me avatar from the three.js examples | Colonist in a suit (outfit colours vary) |
| `Soldier.glb` | Mixamo "Vanguard", three.js examples | Mars trooper in armour (armour colours vary) |

Mixamo characters and animations are free to use in projects under Adobe's Mixamo terms. Ready Player Me avatars follow Ready Player Me's terms. Check both before any commercial use beyond streaming.
